Privacy Policy

Last updated: November 12, 2026

This policy covers clipbot, the private tool that Lab Rat Logic HQ uses to publish its own videos to YouTube and TikTok. clipbot is used only by the channel owner, on the owner's own accounts.

What data the app accesses

clipbot requests a single Google permission: youtube.upload, which lets it upload videos to the YouTube channel of the account that signs in. It uses it for two things only: uploading a video (with its title, description, tags and scheduled publish time) and setting that video's thumbnail. It does not read your email, contacts, watch history, comments, playlists or any other account data, and it never edits or deletes existing videos.

For weekly performance reports, clipbot also reads the public statistics (such as view counts) of the channel's own videos with a YouTube Data API key. This involves no sign-in and no personal data.

How the data is used

The sign-in token is used only to upload the channel owner's own videos to the owner's own channel after the owner approves each episode. It is never used for any other account and never used to show ads or build profiles.

Storage and sharing

The sign-in token is stored in clipbot's private state file inside a private GitHub repository that only the channel owner can access. It is never sold, shared or transferred to third parties. clipbot also keeps a small upload history (which video was uploaded, its YouTube video ID and publish time) in the same private file.

clipbot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

clipbot uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

TikTok

clipbot can also post the channel's Shorts to the Lab Rat Logic HQ TikTok account using TikTok's Login Kit and Content Posting API. It requests only the permissions needed to identify the connected account and to publish or upload that account's own videos (user.info.basic, video.publish and, where used, video.upload), plus video.list to read the account's own video statistics for reports. The TikTok token is stored the same way as the YouTube token and is never shared. See the TikTok Privacy Policy.

Revoking access and deletion

Google access can be revoked at any time at myaccount.google.com/permissions, and TikTok access in the TikTok app under Settings and privacy, Security, Manage app permissions. Stored tokens are deleted on request.
