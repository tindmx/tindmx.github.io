Privacy Policy

Last updated: November 10, 2026

This policy covers clipbot, the application TindmxClips uses to upload videos to YouTube.

What data the app accesses

clipbot requests a single Google permission: youtube.upload, which lets it upload videos to the YouTube channel of the account that signs in. It does not read your email, contacts, watch history, comments, or any other Google account data.

How the data is used

The sign-in token is used only to upload Shorts and set their title, description, tags and publish time on the channel owner's own channel. clipbot is operated solely by the TindmxClips channel owner; no other users sign in to it.

Storage and sharing

The sign-in token is stored encrypted as a secret in a private GitHub repository and is never sold, shared, or transferred to third parties. Upload history (clip IDs, YouTube video IDs, publish times) is stored privately to avoid duplicate uploads.

clipbot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

clipbot uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

TikTok

clipbot can also post the same Shorts to the TindmxClips TikTok account using TikTok's Login Kit and Content Posting API. It requests only user.info.basic (to identify the connected account), video.publish (to post videos to that account) and video.list (to read view, like and comment counts of the account's own posts for performance reports). It does not access messages, followers, or any other TikTok data, and only the channel owner connects an account. TikTok tokens are stored encrypted in private storage and are never shared. Access can be revoked at any time in the TikTok app under Settings and privacy > Security > Manage app permissions.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Stored tokens are deleted on request.
